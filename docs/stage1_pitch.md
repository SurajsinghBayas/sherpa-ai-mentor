# Stage-1 pitch (IM-05)

**Problem:** onboarding takes weeks; knowledge lives in seniors' heads; docs rot.
**Users:** interns, new hires, OSS contributors, eng teams.
**Approach:** agentic mentor over the real repo — ingest → hybrid retrieval → tool loop → verified citations.
**Why grounded:** every claim must resolve to `file:line` in the snapshot; verifier drops the rest; UI shows snippets.
**Built:** architecture map from the real import graph, guided flow tours, cited Q&A, starter tasks, living docs that resync when code changes, and a built-in user-study recorder. Demo repo: fastapi/full-stack-fastapi-template.
